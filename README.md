## 🛡️ Project Overview
This repository contains hands-on **Wireshark traffic analysis projects** focused on packet inspection, network monitoring, and security investigation from a **SOC / Blue Team perspective**.

The labs simulate real-world analyst workflows involving:
- Network traffic analysis
- Suspicious activity detection
- Protocol inspection
- Packet-level investigation
- Threat identification

---

## 🎯 Objectives
- Develop practical packet analysis skills  
- Analyze normal and suspicious network traffic  
- Investigate authentication attempts and protocol behavior  
- Identify Indicators of Compromise (IOCs)  
- Strengthen SOC investigation workflows
