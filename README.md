🛡️ Project Overview

This repository contains hands-on Wireshark traffic analysis projects focused on network monitoring, packet inspection, and security investigation from a SOC / Blue Team perspective.

The labs simulate real-world analyst workflows involving:

traffic analysis
suspicious activity detection
protocol inspection
packet-level investigation
🎯 Objectives
Develop practical packet analysis skills
Analyze normal and suspicious network traffic
Investigate authentication attempts and protocol behavior
Identify indicators of compromise (IOCs)
Strengthen SOC investigation workflows
🧪 Included Projects
🔹 Network Traffic Analysis

Analysis of:

TCP handshakes
DNS requests
HTTP/HTTPS traffic
ICMP communication
🔹 DNS Investigation Lab

Focused on:

DNS queries
suspicious domains
resolution failures
traffic visibility
🔹 Brute Force Detection

Investigation of:

repeated authentication attempts
suspicious login activity
source IP identification
🔹 Malware PCAP Investigation

Analysis of publicly available malicious traffic captures to identify:

command-and-control behavior
suspicious external connections
indicators of compromise
